# 無盡之門 · Infinite Gates

一場沒有盡頭的逃亡。

互動文字冒險遊戲，單文件 HTML，無後端依賴，打開即玩。

## 遊戲特色

- **三大副本**：質數旅館、沉默圖書館、倒計時醫院，各自獨立的世界觀與謎題
- **52 個結局**：死亡、存活、隱藏、真結局，每個選擇都可能走向不同終點
- **29 個成就**：探索、生存、隱藏路線等多類成就可解鎖
- **跨副本繼承**：通關後解鎖繼承變量，影響後續副本的選項與劇情
- **分支樹可視化**：實時顯示已走過的路徑與未解鎖的節點
- **回憶錄與畫廊**：記錄對話、物品、結局插畫與遊戲統計
- **自動播放與快捷鍵**：支援自動推進、鍵盤數字鍵選項、快捷輪盤
- **Web Audio 合成 BGM**：三副本各有獨特和弦進行，無外部音頻文件
- **GM 控制台**：場景跳轉、物品給予、自動遊玩到指定結局（密碼解鎖）

## 本地運行

無需構建、無需伺服器，直接用瀏覽器打開 `index.html` 即可。

```bash
# 或者用任意靜態伺服器
python3 -m http.server 8000
# 然後訪問 http://localhost:8000
```

## 技術棧

- 原生 HTML / CSS / JavaScript（無框架、無構建工具）
- Web Audio API 合成背景音樂
- Canvas 粒子特效
- localStorage 存檔與成就持久化
- 單文件自包含，約 14,500 行

## 操作說明

| 操作 | 方式 |
|---|---|
| 選擇選項 | 點擊按鈕或按鍵盤 1-9 |
| 打開菜單 | 點擊左下角「菜」或按 Esc |
| 自動播放 | 設置中開啟，空白鍵暫停/繼續 |
| 跳過打字 | 點擊文字區或按空白鍵 |
| 保存/讀檔 | 菜單 → 存檔，支援 3 個槽位 + 自動存檔 |

## GM 解鎖

標題頁快速點擊標題 5 次 → 點擊標題中線上方 2 次 → 點擊下方 2 次 → 輸入密碼。解鎖後頂部出現 GM 欄，可使用場景跳轉、物品給予、自動遊玩等功能。
